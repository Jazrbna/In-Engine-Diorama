# In-Engine-Diorama

INITIAL PROJECT BRIEF

For this artefact I will choose to recreate a rough imitation of an in-game mechanic listed under PDF IN ENGINE DIORAMA pg 1, listed route 2. The chosen game will be Red Dead Redemption, the mechanic being the games unique Dead-eye combat skill in which when pressing Q, tick time is slowed and the user is free to aim, scope and fire at chosen enemies with enhanced damage and headshot range probability to execute high-precision shots.
